# i18n.sh

Utilities for translating messages and formatting values for a locale

>
> Jump to: [Overview](#overview) · [See also](#see-also) · [Tips](#tips) · [Reference](#reference)

<a id="overview"></a>
## ✨ Overview

This module covers the two halves of speaking a user's language. The first
is internationalization: message catalogs, a locale fallback chain, named
placeholders, and plural forms chosen by the rules of the target language
rather than by `count == 1`. The second is localization: numbers, currency,
percentages, byte sizes, dates, times, and relative times rendered the way
the locale writes them, plus the direction the text reads in.

Two decisions shape everything else.

Month names, weekday names, and date patterns come from tables this module
owns, never from `LC_TIME`. Asking `date` for a German month name only works
when the host has generated the German locale, and when it has not, `date`
silently answers in English. A localization library that returns the wrong
language rather than an error is worse than useless, so the only thing
`date` is asked for is the numeric calendar fields, under `LC_ALL=C`.

Fractional values are rendered by manipulating digit strings, never through
`printf '%f'`. That conversion follows `LC_NUMERIC`, so on a machine with a
German numeric locale it produces `1234,50`, which is precisely the bug this
module exists to prevent; it also writes a warning to standard error when
the locale is missing. Working on strings avoids both, and has the side
benefit of formatting integers wider than 64 bits exactly.

Catalogs are read from a dependency-free `key = value` format and from GNU
gettext `.po` files. Nothing here needs `jq`, `gettext`, `bc`, or `awk`.

### 🌍 Environment

| Variable | Type | Description |
| --- | --- | --- |
| **`DYBATPHO_I18N_LOCALE`** | string | Locale to use, overriding the environment |
| **`DYBATPHO_I18N_FALLBACK`** | string | Locale consulted when the active one has no translation, default is `en` |
| **`DYBATPHO_I18N_PATH`** | string | Colon-separated catalog directories, searched before the XDG and system ones |
| **`DYBATPHO_I18N_DOMAIN`** | string | Default catalog domain, default is `messages` |
| **`DYBATPHO_I18N_STRICT`** | string | When true-like, a missing translation or catalog stops the script |
| **`DYBATPHO_I18N_MISSING_MARK`** | string | When set, an untranslated key is rendered wrapped in this marker |
| **`DYBATPHO_I18N_TRANSLATE_LIBRARY`** | string | When true-like, dybatpho's own diagnostics are translated too |
| **`DYBATPHO_I18N_BYTE_STANDARD`** | string | `iec` for 1024-based KiB/MiB, `si` for 1000-based kB/MB, default is `iec` |
| **`DYBATPHO_I18N_CURRENCY_NEGATIVE`** | string | `sign` for `-$1.00` or `parens` for accounting style `($1.00)` |
| **`DYBATPHO_I18N_ASCII`** | string | When true-like, prefer ASCII over currency symbols and exotic spaces |
| **`DYBATPHO_I18N_NOW`** | number | Epoch seconds used as "now" by relative time, for reproducible output |

### 🚀 Highlights

- [`dybatpho::i18n_reset`](#dybatphoi18n_reset) — Forget every loaded catalog, the resolved locale, and the recorded misses. Loading is tracked per shell, so a script that changes `DYBATPHO_I18N_PATH` at run time calls this before loading again.
- [`__dybatpho_i18n_normalize`](#__dybatpho_i18n_normalize) — Split a locale tag into its parts and build the canonical form. Accepts the POSIX spelling `pt_BR.UTF-8@euro` and the BCP-47 spelling `zh-Hant-TW`, and normalizes both to `lang[_Script][_REGION][@modifier]`.
- [`__dybatpho_i18n_language`](#__dybatpho_i18n_language) — Print the language subtag of a locale.
- [`__dybatpho_i18n_resolve`](#__dybatpho_i18n_resolve) — Resolve the locale the runtime should use, honoring an explicit override first and then the POSIX environment variables in the order the specification gives them.
- [`dybatpho::i18n_locale`](#dybatphoi18n_locale) — Print the locale currently in effect, resolving it on first use.
- [`dybatpho::i18n_set_locale`](#dybatphoi18n_set_locale) — Use a locale for every later translation and formatting call.
- [`dybatpho::i18n_chain`](#dybatphoi18n_chain) — Print the fallback chain a lookup walks for a locale, most specific first. A catalog that translates three keys for `zh_Hant_TW` and the rest for `zh` needs no duplication because of this chain.
- [`__dybatpho_i18n_check_key`](#__dybatpho_i18n_check_key) — Fail unless a message key can be stored and looked up safely. The key becomes part of a composite associative-array subscript, so the one byte that has to be excluded is the separator joining it. Everything else is allowed on purpose: a gettext catalog uses whole English sentences as message ids, and rejecting punctuation would make those unusable.
- [`__dybatpho_i18n_store`](#__dybatpho_i18n_store) — Record one translation.
- [`__dybatpho_i18n_lookup`](#__dybatpho_i18n_lookup) — Look a key up along the fallback chain of the active locale.
- [`__dybatpho_i18n_interpolate`](#__dybatpho_i18n_interpolate) — Substitute `{name}` placeholders in a template. The scan splits the template on each brace and concatenates rather than using `${variable//pattern/replacement}`. Bash 5.2 enabled `patsub_replacement`, which makes an unescaped `&` in the replacement expand to the text that matched, while the backslash escape that fixes it is taken literally on 5.1 and earlier. Translations are data and routinely contain `&`, so neither form is correct across the versions this library supports. Concatenation has neither behavior anywhere.
- [`__dybatpho_i18n_plural_other`](#__dybatpho_i18n_plural_other) — Print `other` for a language with a single cardinal form.
- [`__dybatpho_i18n_plural_one`](#__dybatpho_i18n_plural_one) — Print the plural category for a one-versus-other language.
- [`__dybatpho_i18n_plural_fr`](#__dybatpho_i18n_plural_fr) — Print the plural category for French, which counts zero as singular.
- [`__dybatpho_i18n_plural_pt`](#__dybatpho_i18n_plural_pt) — Print the plural category for Portuguese, which counts zero as singular.
- [`__dybatpho_i18n_plural_hi`](#__dybatpho_i18n_plural_hi) — Print the plural category for Hindi and its relatives, which count zero as singular.
- [`__dybatpho_i18n_plural_ru`](#__dybatpho_i18n_plural_ru) — Print the plural category for Russian and the other East Slavic languages. The singular test is on the last digit, not on the whole number, which is what separates this rule from the Polish one below.
- [`__dybatpho_i18n_plural_pl`](#__dybatpho_i18n_plural_pl) — Print the plural category for Polish, whose singular is the number one itself rather than anything ending in one.
- [`__dybatpho_i18n_plural_cs`](#__dybatpho_i18n_plural_cs) — Print the plural category for Czech and Slovak. Their `many` category applies only to fractions, which integer counts never produce.
- [`__dybatpho_i18n_plural_ar`](#__dybatpho_i18n_plural_ar) — Print the plural category for Arabic, the one language that uses all six.
- [`__dybatpho_i18n_plural_he`](#__dybatpho_i18n_plural_he) — Print the plural category for Hebrew, which has a dual form.
- [`__dybatpho_i18n_plural_lt`](#__dybatpho_i18n_plural_lt) — Print the plural category for Lithuanian.
- [`__dybatpho_i18n_plural_lv`](#__dybatpho_i18n_plural_lv) — Print the plural category for Latvian, which has a zero form.
- [`__dybatpho_i18n_plural_ro`](#__dybatpho_i18n_plural_ro) — Print the plural category for Romanian.
- [`__dybatpho_i18n_plural_sl`](#__dybatpho_i18n_plural_sl) — Print the plural category for Slovenian, which has a dual form.
- [`__dybatpho_i18n_plural_is`](#__dybatpho_i18n_plural_is) — Print the plural category for Icelandic.
- [`__dybatpho_i18n_plural_mk`](#__dybatpho_i18n_plural_mk) — Print the plural category for Macedonian.
- [`__dybatpho_i18n_plural_fil`](#__dybatpho_i18n_plural_fil) — Print the plural category for Filipino and Tagalog.
- [`__dybatpho_i18n_plural_cy`](#__dybatpho_i18n_plural_cy) — Print the plural category for Welsh, which uses all six.
- [`__dybatpho_i18n_plural_mt`](#__dybatpho_i18n_plural_mt) — Print the plural category for Maltese.
- [`__dybatpho_i18n_plural_ga`](#__dybatpho_i18n_plural_ga) — Print the plural category for Irish.
- [`__dybatpho_i18n_plural_gd`](#__dybatpho_i18n_plural_gd) — Print the plural category for Scottish Gaelic.
- [`dybatpho::i18n_plural_form`](#dybatphoi18n_plural_form) — Print the CLDR plural category a count takes in a language.
- [`__dybatpho_i18n_plural_category`](#__dybatpho_i18n_plural_category) — Print the CLDR plural category for a count in a language.
- [`__dybatpho_i18n_miss`](#__dybatpho_i18n_miss) — Record an untranslated key, and stop the script when strict mode asked for that. Recording is best effort: `dybatpho::i18n_t` is normally called inside a command substitution, which is a subshell, so a miss seen there cannot reach the parent. `dybatpho::i18n_lint` is the reliable way to find untranslated keys.
- [`__dybatpho_i18n_fallback_text`](#__dybatpho_i18n_fallback_text) — Render the text shown when a key has no translation.
- [`dybatpho::i18n_t`](#dybatphoi18n_t) — Translate a message and fill in its placeholders. An argument shaped like `name=value` binds `{name}`; any other argument is bound to the next position, so `{1}` is the first of them.
- [`dybatpho::i18n_tn`](#dybatphoi18n_tn) — Translate a message, choosing the plural form the count takes in the target language. The count is bound to `{count}` and `{n}` on top of any bindings given, and is grouped for the locale before being substituted.
- [`dybatpho::i18n_tc`](#dybatphoi18n_tc) — Translate a message that is qualified by a context, so that one English word with two meanings can be translated two ways.
- [`dybatpho::i18n_has`](#dybatphoi18n_has) — Report whether a key has a translation, without recording a miss and without rendering anything. This is the predicate to branch on.
- [`dybatpho::i18n_missing`](#dybatphoi18n_missing) — Print every key that was looked up and not found in this shell.
- [`dybatpho::i18n_library_message`](#dybatphoi18n_library_message) — Translate a diagnostic that dybatpho itself emitted. Library call sites are not rewritten to use message keys; the English text is the key, which is how gettext works and what lets one hook cover every `dybatpho::die`, `warn`, and `error` in the library at once. The hook is inert unless it is switched on, so output is byte for byte unchanged by default and the existing test suite is unaffected.
- [`dybatpho::i18n_library_text`](#dybatphoi18n_library_text) — Translate a piece of dybatpho's own user interface that carries a value. The English text a call site already builds cannot serve as the message id here, because the value is baked into it and no catalog can list `Unrecognized option: --colr`. So the caller names a stable key and hands over the English rendering it would otherwise have printed; the key is what translators see, and the English is what is printed whenever the hook is off, the module is absent, or the key is untranslated.
- [`dybatpho::i18n_library_plural`](#dybatphoi18n_library_plural) — Translate a piece of dybatpho's own user interface that counts something, choosing the plural form the count takes in the target language. This is the half a generated English string cannot express: the call site picks between `argument` and `arguments` by testing for one, which is the wrong question in Russian and a question Vietnamese never asks.
- [`__dybatpho_i18n_seed_symbols`](#__dybatpho_i18n_seed_symbols) — Seed the locale data that cannot be written as ASCII source. French and Russian group digits with a narrow no-break space, and the currency layouts separate symbol from amount with a non-breaking space, so that neither a terminal nor a text wrapper can split an amount. Older or reduced `printf` builds do not understand `\u`, so the escape is probed once and degraded rather than assumed.
- [`__dybatpho_i18n_data`](#__dybatpho_i18n_data) — Read one field of locale data, degrading from the exact tag to the bare language, then to the configured fallback, then to English. The last step matters: a missing group separator that came back empty would silently turn 1234 into 1234 rather than 1,234.
- [`__dybatpho_i18n_split_number`](#__dybatpho_i18n_split_number) — Split a decimal number into sign, integer digits, and fraction digits. No arithmetic touches the integer part, so a value wider than a 64-bit integer survives intact where `$(( ))` would wrap to nonsense.
- [`__dybatpho_i18n_round`](#__dybatpho_i18n_round) — Round a fraction to a width, carrying into the integer part. Both sides stay digit strings, so a thirty digit value rounds exactly the same way a small one does. Ties round away from zero, which is what a person reading an invoice expects; note that `printf` rounds binary floats to even and so disagrees on exact halves.
- [`__dybatpho_i18n_group`](#__dybatpho_i18n_group) — Insert a group separator into a string of digits, honoring a secondary group size when the locale has one.
- [`dybatpho::i18n_number`](#dybatphoi18n_number) — Format a number the way a locale writes it.
- [`dybatpho::i18n_number_plain`](#dybatphoi18n_number_plain) — Format a number without grouping and with a dot decimal mark, whatever the locale. This is the rounding primitive for machine-readable output, and exists so that nothing in a script has to reach for `printf '%f'`, which follows `LC_NUMERIC` and would vary by machine.
- [`dybatpho::i18n_percent`](#dybatphoi18n_percent) — Format a value as a percentage the way a locale writes it.
- [`__dybatpho_i18n_negative`](#__dybatpho_i18n_negative) — Move a negative sign outside the rendered amount, or wrap the amount in parentheses when accounting style was asked for. Without this a prefix symbol produces `$-1,234.50`, which no locale writes.
- [`dybatpho::i18n_currency`](#dybatphoi18n_currency) — Format a monetary amount for a locale. How many decimal digits to show is a property of the currency, while how the digits are grouped and where the symbol sits are properties of the locale, so the same euro amount reads `€1,234.50` in English and `1.234,50 €` in German, and yen never shows a decimal at all.
- [`dybatpho::i18n_bytes`](#dybatphoi18n_bytes) — Format a byte count for people, grouping the digits for the locale. Units stay in their international symbols: `KiB` and `MB` are symbols rather than words, every other tool on the machine prints them that way, and translating them would break anything parsing the output.
- [`__dybatpho_i18n_name`](#__dybatpho_i18n_name) — Read one name out of a comma separated list of them.
- [`dybatpho::i18n_month_name`](#dybatphoi18n_month_name) — Print the name of a month in a locale.
- [`dybatpho::i18n_weekday_name`](#dybatphoi18n_weekday_name) — Print the name of a weekday in a locale.
- [`__dybatpho_i18n_date_fields`](#__dybatpho_i18n_date_fields) — Read the numeric calendar fields of a timestamp. This is the only place the module runs `date`, and it asks only for numbers, which are the same in every locale. `LC_ALL=C` is scoped to the function and inherited by the child process, so the result cannot vary with the ambient locale; it is never exported.
- [`__dybatpho_i18n_hour12`](#__dybatpho_i18n_hour12) — Convert a 24-hour hour into its 12-hour form.
- [`__dybatpho_i18n_render_pattern`](#__dybatpho_i18n_render_pattern) — Render a CLDR-style pattern against calendar fields. Supported fields are `yyyy`, `yy`, `MMMM`, `MMM`, `MM`, `M`, `dd`, `d`, `EEEE`, `EEE`, `HH`, `H`, `hh`, `h`, `mm`, `ss`, and `a`, plus `'literal'`. Anything else stops the caller by name, so a typo in a registered pattern fails immediately rather than rendering something subtly wrong.
- [`__dybatpho_i18n_dayperiod`](#__dybatpho_i18n_dayperiod) — Print the day period marker an hour falls in.
- [`__dybatpho_i18n_pattern`](#__dybatpho_i18n_pattern) — Look a date or time pattern up, degrading within the locale before it degrades to another one, so a locale that defines only the short and medium forms still renders the long ones sensibly.
- [`dybatpho::i18n_date`](#dybatphoi18n_date) — Format a timestamp as a date the way a locale writes it.
- [`dybatpho::i18n_time`](#dybatphoi18n_time) — Format a timestamp as a time of day the way a locale writes it, including whether it uses a 12-hour or a 24-hour clock.
- [`dybatpho::i18n_datetime`](#dybatphoi18n_datetime) — Format a timestamp as a date and time together.
- [`dybatpho::i18n_date_pattern`](#dybatphoi18n_date_pattern) — Format a timestamp against an explicit pattern.
- [`__dybatpho_i18n_seed_relative`](#__dybatpho_i18n_seed_relative) — Seed the English strings this module needs for relative time. They live in the catalog rather than in the code so that they can be translated like any other message, and they are stored under the `en` locale so the normal fallback chain reaches them.
- [`__dybatpho_i18n_span`](#__dybatpho_i18n_span) — Choose the unit and count that best describe a span of seconds. The thresholds are the conventional ones rather than exact unit multiples, because an hour and fifty minutes reads better as two hours than as a hundred and ten minutes. Months and years use the average Gregorian length, so they are approximate by design.
- [`dybatpho::i18n_relative`](#dybatphoi18n_relative) — Describe when a timestamp happened relative to another one.
- [`dybatpho::i18n_duration`](#dybatphoi18n_duration) — Describe a span of time without saying whether it is past or future.
- [`dybatpho::i18n_is_rtl`](#dybatphoi18n_is_rtl) — Report whether a locale is written right to left.
- [`dybatpho::i18n_direction`](#dybatphoi18n_direction) — Print the direction a locale is written in.
- [`dybatpho::i18n_bidi_mark`](#dybatphoi18n_bidi_mark) — Print a bidirectional mark, which forces the direction of the text around it without being visible itself.
- [`dybatpho::i18n_bidi_isolate`](#dybatphoi18n_bidi_isolate) — Wrap text so that its direction cannot leak into the text around it. The default isolates by first strong character, which is what to use when splicing in a value whose language is not known in advance.
- [`dybatpho::i18n_bidi_strip`](#dybatphoi18n_bidi_strip) — Remove every bidirectional control character from text, so that it can be compared or measured.
- [`dybatpho::i18n_register_number`](#dybatphoi18n_register_number) — Add or replace the number symbols of a locale.
- [`dybatpho::i18n_register_currency`](#dybatphoi18n_register_currency) — Add or replace a currency's symbol and decimal digits.
- [`dybatpho::i18n_register_currency_layout`](#dybatphoi18n_register_currency_layout) — Set where a locale puts a currency symbol.
- [`dybatpho::i18n_register_date`](#dybatphoi18n_register_date) — Add or replace one date or time pattern of a locale.
- [`dybatpho::i18n_register_names`](#dybatphoi18n_register_names) — Add or replace a locale's month, weekday, or day period names.
- [`dybatpho::i18n_register_rtl`](#dybatphoi18n_register_rtl) — Record additional languages as being written right to left.
- [`__dybatpho_i18n_read_msg`](#__dybatpho_i18n_read_msg) — Read a native `key = value` catalog. The quoting rules are those of the `config` module's dotenv reader, so a value in double quotes has its escapes expanded and one in single quotes is taken literally. A plural form is written `key[category]`, which keeps the format flat and one line per entry while leaving the dot free for hierarchical keys: writing `menu.file.one` as a plural would be ambiguous.
- [`__dybatpho_i18n_po_unescape`](#__dybatpho_i18n_po_unescape) — Turn the body of a `.po` string into its text. `printf '%b'` does not know about `\"`, so the escaped quotes are lifted out before it runs and put back afterwards.
- [`__dybatpho_i18n_read_po`](#__dybatpho_i18n_read_po) — Read a GNU gettext `.po` catalog. The subset parsed is the one that carries translations: `msgctxt`, `msgid`, `msgid_plural`, `msgstr`, and `msgstr[N]`, including strings continued over several lines. Obsolete entries are skipped, and so are fuzzy ones, because gettext treats a fuzzy entry as an unreviewed guess rather than a translation. An empty `msgstr` means untranslated, not "translates to nothing", which is what makes a template file load as empty rather than as a catalog of blanks. The header's `Plural-Forms` expression is read for its count but never evaluated. A catalog is a data file that arrives from a translation platform, and turning an arbitrary C expression from one into shell arithmetic would be a way to run code. The CLDR rules this module carries decide the category instead, and `msgstr[N]` indices are mapped onto them.
- [`__dybatpho_i18n_po_flush`](#__dybatpho_i18n_po_flush) — Store the entry the parser has just finished reading, singular or plural, and drop it when it is marked fuzzy: a fuzzy entry is a translator's draft, not a translation.
- [`__dybatpho_i18n_load_file`](#__dybatpho_i18n_load_file) — Load a catalog file, at most once per shell.
- [`__dybatpho_i18n_roots`](#__dybatpho_i18n_roots) — Print the directories a catalog is looked for in, least specific first. The order is deliberately the reverse of how specific each root is: a later file overrides an earlier one, so the directories a caller named themselves have to be loaded last in order to win.
- [`__dybatpho_i18n_discover`](#__dybatpho_i18n_discover) — Load every catalog that exists for a locale and domain, across the whole search path and both file layouts.
- [`dybatpho::i18n_load`](#dybatphoi18n_load) — Load message catalogs. With a file, that file is loaded for the given locale. Without one, every catalog on the search path is loaded for each locale in the fallback chain, so that a partially translated locale is backed by the ones behind it.
- [`dybatpho::i18n_init`](#dybatphoi18n_init) — Resolve the locale and load its catalogs, once. Call this in the shell the script runs in. Translation is normally used inside a command substitution, which is a subshell, so a catalog loaded there would be discarded the moment the substitution returned.
- [`dybatpho::i18n_locales`](#dybatphoi18n_locales) — Print the locales that have a catalog somewhere on the search path.
- [`__dybatpho_i18n_literal`](#__dybatpho_i18n_literal) — Read the first argument of a translation call, when it is a literal this tool can be sure of. A key assembled from a variable cannot be resolved by reading the source, so it is reported rather than guessed at. That report is the point: it tells the author exactly which call sites the tooling cannot see.
- [`__dybatpho_i18n_scan`](#__dybatpho_i18n_scan) — Collect every translation key a set of sources refers to.
- [`dybatpho::i18n_extract`](#dybatphoi18n_extract) — Write a catalog template covering every key a source tree refers to, so a translator has something to fill in rather than a blank file.
- [`__dybatpho_i18n_placeholders`](#__dybatpho_i18n_placeholders) — Print the placeholders a template uses, one per line, sorted.
- [`dybatpho::i18n_lint`](#dybatphoi18n_lint) — Compare a locale's catalog against a reference one and report what a translator still has to do. The placeholder check is the one worth running in continuous integration: a translation that dropped `{count}` looks perfectly fine until the moment it is rendered.
- [`__dybatpho_i18n_finding`](#__dybatpho_i18n_finding) — Print one lint finding in the requested shape.

<a id="tips"></a>
## 💡 Tips

### `dybatpho::i18n_t`

- Call `dybatpho::i18n_init` or `dybatpho::i18n_load` in the parent shell. This function is almost always used inside `$( )`, which is a subshell, so a catalog loaded from within it is discarded as soon as it returns

### `dybatpho::i18n_number`

- Formatted output is for display. Never parse it back: several locales group with a narrow no-break space, which is invisible but is not a space

### `dybatpho::i18n_bytes`

- `dybatpho::file_size` and `dybatpho::dir_size` return the raw byte count this takes

### `dybatpho::i18n_date`

- This takes epoch seconds. Convert a date string first with `dybatpho::date_parse`

### `dybatpho::i18n_relative`

- Pass the second argument in tests. Leaving it to the clock is what makes a suite that formats relative times flake

### `dybatpho::i18n_bidi_isolate`

- Wrap for display only. These are invisible but real characters, so text that has been wrapped no longer compares equal to text that has not. Never put them in a filename, a config value, a JSON payload, or anything another program will compare. They also count toward `${#text}`, so strip them with `dybatpho::i18n_bidi_strip` before measuring a column width

### `dybatpho::i18n_reset`

Forget every loaded catalog, the resolved locale, and the
recorded misses. Loading is tracked per shell, so a script that changes
`DYBATPHO_I18N_PATH` at run time calls this before loading again.

_Function has no arguments._

### `__dybatpho_i18n_normalize`

Split a locale tag into its parts and build the canonical form.
Accepts the POSIX spelling `pt_BR.UTF-8@euro` and the BCP-47 spelling
`zh-Hant-TW`, and normalizes both to `lang[_Script][_REGION][@modifier]`.

| Name | Type | Description |

### `__dybatpho_i18n_read_po`

Read a GNU gettext `.po` catalog.
The subset parsed is the one that carries translations: `msgctxt`, `msgid`,
`msgid_plural`, `msgstr`, and `msgstr[N]`, including strings continued over
several lines. Obsolete entries are skipped, and so are fuzzy ones, because
gettext treats a fuzzy entry as an unreviewed guess rather than a
translation. An empty `msgstr` means untranslated, not "translates to
nothing", which is what makes a template file load as empty rather than as a
catalog of blanks.

The header's `Plural-Forms` expression is read for its count but never
evaluated. A catalog is a data file that arrives from a translation
platform, and turning an arbitrary C expression from one into shell
arithmetic would be a way to run code. The CLDR rules this module carries
decide the category instead, and `msgstr[N]` indices are mapped onto them.

**🧾 Arguments**

| Name | Type | Description |
| --- | --- | --- |
| `$1` | string | File path |
| `$2` | string | Locale the entries belong to |

**🧩 Variable sets**

- **`__dybatpho_i18n_msg`**: __dybatpho_i18n_plural
